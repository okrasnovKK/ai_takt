# ai-takt

**Корпоративный Event-Manager-Agent** — Telegram-бот для управления мероприятиями, опросами и внутренними коммуникациями команды.

Бот: [@ai_takt_bot](https://t.me/ai_takt_bot)  
Стек: Python 3, aiogram 3.x, JSON-база

---

## Возможности

### 👥 Управление командой
- Автоматическая регистрация новых сотрудников при `/start` или первом сообщении
- База сотрудников в `employee_base.xlsx` (10 полей: личные данные, навыки, хобби)
- Приветственный onboarding-опрос для новых участников (7 вопросов)
- Логирование всех входящих сообщений (`data/incoming_messages.jsonl`)

### 🎉 Полный цикл мероприятий
Жизненный цикл мероприятия из 9 состояний:
1. **Proposal** — предложение форматов на основе хобби команды
2. **Budgeting** — детальная смета по категориям
3. **Approval** — согласование ЛПР (только в личку, не в общий чат)
4. **Planning** — календарь задач с дедлайнами
5. **Chat Created** — отдельный чат мероприятия
6. **Program Published** — программа + тайминг
7. **Active** — проведение
8. **Completed** — пост-опрос участников (анонимный)
9. **Memories Video** — Seedance 2.0 AI-видео + монтаж (OpenCV/ffmpeg)

Команды: `/event_help`, `/event_propose`, `/event_list`, `/event_status`, `/event_budget`, `/event_approve`, `/event_reject`, `/event_date`, `/event_tasks`, `/event_task_done`, `/event_chat_set`, `/event_invite`, `/event_program`, `/event_vote`, `/event_launch`, `/event_complete`, `/event_survey_post`, `/event_video`

### 📊 Три типа опросов
| Опрос | Тип | Анонимность | Хранение |
|-------|-----|------------|----------|
| **Onboarding** | При вступлении | Виден команде | `employee_base.xlsx` |
| **Event Survey** | После мероприятия | **Абсолютно анонимный** | Отдельный Excel на мероприятие |
| **Pulse Survey** | Ежеквартальный | **Анонимный**, агрегация по темам | `Опрос_вовлеченности_Q{N}_{Год}.xlsx` |

Результаты pulse-опросов агрегируются в тематические кластеры (никогда не привязываются к именам).

### 🎬 Медиа-пайплайн
- **Media Review** — этический пре-скрининг фото/видео через Vision LLM перед монтажом. Human-in-the-loop с командами `/media_review`, `/media_report`, `/media_approve`, `/media_reject`
- **Video Montage** — локальный монтаж на OpenCV + ffmpeg: фото + видео, кроссфейды, титры, фоновая музыка, audio ducking, H.264 High Profile +faststart (совместимость iOS/Android)
- **AI Video** — генерация видео через OpenRouter (Seedance 2.0, $0.21 за 8-сек 720p)

### 🎄 Украшение помещений
Конечный автомат (FSM) для оформления офиса к праздникам:
`/holiday_start` → фото → тема/бюджет → AI-концепт → утверждение → смета → **ссылки на закупку** (Ozon/Wildberries)

### 🎂 Дни рождения
Автоматический пайплайн: проверка `employee_base.xlsx` за 5 дней до месяца → генерация текста + AI-открытки (GPT-5 Image) → отправка ЛПР на утверждение → публикация в чат команды.

### 📢 Коммуникации
- Отправка в командный чат, личные сообщения, event-чаты
- Broadcast всем зарегистрированным пользователям
- Анти-дубликат (60-секундное окно) для текста, фото и видео
- Публикация приглашений и программ в целевые чаты

### 🔒 LPR-протокол
Чувствительная информация (предложения форматов, бюджеты, сметы) направляется **только ЛПР в личные сообщения** — никогда в общий чат. Утверждение мероприятий — только через явную команду `/event_approve`.

## Быстрый старт

### 1. Клонирование и установка

```bash
git clone https://github.com/okrasnovKK/ai_takt.git
cd ai_takt
pip install -r requirements.txt
```

### 2. Конфигурация

Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=1234567890:AA...xyz          # токен бота от @BotFather
TEAM_CHAT_ID=-5177914561               # ID командного чата
LPR_USER_ID=123456789                  # ID ЛПР (опционально, для приватной маршрутизации)
```

### 3. Запуск

```bash
python run.py
```

## CLI

```bash
# Коммуникации
python cli.py chat "Привет, команда!"                 # в командный чат
python cli.py user 123456789 "Личное сообщение"        # конкретному пользователю
python cli.py broadcast "Всем привет!"                 # всем зарегистрированным
python cli.py users                                    # список пользователей
python cli.py photo путь/к/фото.jpg "Подпись"          # фото в чат
python cli.py video путь/к/видео.mp4 "Подпись"         # видео в чат
python cli.py incoming                                 # входящие сообщения

# Pulse-опрос
python cli.py pulse_survey                             # запустить pulse-опрос

# Мероприятия
python cli.py events                                   # список мероприятий
python cli.py event-create "Название" team_building     # создать
python cli.py event-status [id]                        # статус мероприятия
python cli.py event-approve <id> [комментарий]          # согласовать
python cli.py event-budget <id>                        # показать смету
```

## Технические особенности

- **aiogram 3.x** — асинхронный Telegram Bot API
- **JSON-база** — все состояния персистентны, переживают перезапуск бота
- **FSM (конечные автоматы)** — holiday decor, onboarding-опросы, мероприятия
- **Анти-дубликат** — 60-секундное окно для текста, фото и видео
- **Анонимность опросов** — жёстко на уровне кода: event/pulse ответы никогда не связываются с именами
- **LPR-протокол** — бюджеты и предложения только в личку ЛПР, утверждение явной командой
- **Кроссплатформенное видео** — H.264 High Profile +faststart (iOS + Android)
